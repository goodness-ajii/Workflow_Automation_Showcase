## Work in Production

**Email to Operations Tracker Automation** (live since September 2026)
Incoming emails are read by Gemini, which extracts the task, owner, priority, and deadline, then writes a clean row into a shared Google Sheets tracker used for daily executive operations. Tested across single task emails, vague deadlines, informational updates, and emails with multiple actions. Known limitation documented: emails with several equal priority actions create one row for the primary action.
*Stack: Gmail, Google Workspace Studio, Gemini, Google Sheets*

**Structured Content Generation Pipeline**
Designed a batch generation pipeline that produced 3,300 structured exam questions across 11 chapters, with fixed rules for difficulty balance, question type balance, answer rationales, and output format.
*Stack: Claude, batch generation, structured markdown output*
